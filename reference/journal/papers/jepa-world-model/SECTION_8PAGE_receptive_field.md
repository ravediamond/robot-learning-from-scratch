# 8-page section: perturbation receptive field (WS-116, exploratory)

Source: `projects/jepa-surprise-receptive-field/README.md` (generated by `scripts/ws116_writeup.py`).

We froze a protocol (WS-108) to ask which perturbation classes three latent-surprise monitors can see on logged
SO-101 rollouts, gated by a sanity bar: a wrong-action perturbation (class 5) must reach AUROC ≥ 0.9. None did:
M1 (W1 world model) 0.775, M2 0.766, M3 (VLA-JEPA predictor) 0.501. Under the frozen rule no
receptive-field table is read, and the question stays open. M1's value is not a load or scorer fault: the scorer
reproduces the earlier K=30 corruption ratios. M3 takes the action tokens as input, yet shuffling them across
episodes barely moves its loss (5 anchors, `projects/jepa-surprise-receptive-field/results/M3_diag_action_shuffle.json`):
in this exploratory check the predictor is near action-blind.

# Model answers

1. Input embedding (token → vector) and output projection (vector → token score) are naturally related: similar tokens should be close in both. Tying cuts parameters (38.6M of 124M for GPT-2 small), regularizes, and helps rare tokens get gradients through both roles. Not tied: when input and output vocabularies differ, or in large models where the embedding is a small fraction and untied gives a bit more capacity (LLaMA is untied).
2. Each block adds two terms to the residual stream; with L blocks the stream's variance grows like 2L × (variance of each contribution). Scaling those output projections by 1/√(2L) keeps the stream's variance roughly constant at init, so deep stacks start stable.
3. Learned positions were simple and worked well for a fixed max length. Position 1025 has no embedding: the model cannot run past 1024 tokens without retraining or interpolation tricks; RoPE/ALiBi models extrapolate somewhat.
4. Per token per layer: attention projections 4D² (c_attn 3D² + c_proj D²), MLP 8D², attention scores/values 2·T·D. At T = 1024, D = 768: projections + MLP = 12D² ≈ 7.1M MACs, attention ≈ 1.6M MACs → MLP + projections dominate (~80%). lm_head: V·D = 38.6M MACs per token, once: larger than one layer, so the vocab projection is a big cost too for a small model.
5. clone() made a copy; nn.Parameter registered it as a new, separate trainable weight. Caught in 10 seconds by `model.lm_head.weight is model.wte.weight` (or data_ptr equality) or by the parameter count.
6. Keeps: transformer blocks, pre-norm, attention, the VLM's embeddings and vision encoder. Cuts: the upper half of the VLM layers, the language-model head (no text generation needed), visual tokens (pixel shuffle to 64). Changes: adds a separate action expert (smaller width) with cross-attention to VLM features and causal self-attention over action tokens, trained with flow matching instead of next-token cross-entropy.

# Model answers

1. g = 2(pred − y)/(N·O), shape (N, O). dW must be (O, I): only g.T @ x fits. db = g summed over N. dx = g @ W, (N, I). dx matters because x is usually not data but the output of the previous layer (backprop continues through it), and for input-gradient methods (saliency, adversarial perturbations, latent planning by gradient descent on actions).
2. Because a parameter used in several places of the graph must receive the sum of all its contributions; accumulation implements that for free. Legitimate use: gradient accumulation, i.e. several micro-batches → backward each → one optimizer step, to emulate a big batch on small memory.
3. The update at step k is lr × (g₁ + … + g_k). It behaves like heavy-ball momentum with β = 1: w overshoots 3, the accumulated sum keeps pushing, then reverses slowly. It oscillates (and with a larger lr diverges). Not "slower convergence": it never settles.
4. `no_grad`: a context where operations are not recorded (no graph, less memory). For eval and for parameter updates. `detach`: one tensor cut from the graph, inside an otherwise recorded computation. `model.eval()`: has nothing to do with gradients; it switches layer behavior (dropout off, BatchNorm uses running stats). Eval usually needs both `eval()` and `no_grad()`.
5. Without stop-gradient, both branches can satisfy "prediction = target" by outputting the same constant for every input: the loss reaches 0, the representation carries no information (collapse). Stop-gradient breaks the symmetry; EMA makes the target move slowly so the online network chases a stable but improving target. (LeWM drops both and uses a Gaussian regularizer, SIGReg, instead: see `knowledge/05-jepa-ssl.md`.)
6. (1) Is the input data finite and normalized (nan/inf in a batch, a std of 0)? (2) LR too high: plot loss and grad norm before the NaN; add gradient clipping. (3) Ops with singular points: log(0), sqrt(0) gradient, division by a small std, exp overflow; fp16 overflow. (4) Find the first NaN: `torch.autograd.set_detect_anomaly(True)` or hooks that assert finite activations per layer. (5) Reproduce on that exact batch with a fixed seed, overfit-one-batch.
7. Forward difference error is O(eps); central is O(eps²) because the even terms of the Taylor series cancel. float64 because with float32 the rounding error ~1e-7/eps dominates for small eps; in float64 you can use eps = 1e-5 to 1e-6 and get ~1e-10 accuracy.

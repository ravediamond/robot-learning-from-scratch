# W9 D2: Timed mock coding (45 minutes, blank files)

Coding list Tier 1–2 (`reference/journal/book/exercises/coding/README.md`). This is the live-coding round.

## Protocol (as in the room)
- Timer on. No notes, no docs, no AI, no autocomplete. Talk out loud: shapes as you type, edge cases before running.
- Order and budgets: `m1_attention.py` (10 min) → `m2_flow.py` (12 min) → `m3_cem.py` (13 min) → `m4_bootstrap.py` (10 min).
- Each file has only signatures. Run `uv run pytest weeks/w9-mock-interviews/d2-timed-coding -k m1` etc.
- Write the time each took on the first line of each file. Over budget → redo it tomorrow from blank.
- Record yourself once. Listen: did you say the shapes? Did you test a tiny case by hand?

The `questions.md` file has the follow-ups an interviewer asks AFTER the code works.

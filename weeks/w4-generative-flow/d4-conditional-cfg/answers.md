# Model answers

1. v_uncond comes from the same network with the null condition; if null was never seen in training, its output is untrained garbage, and CFG extrapolates along (v_c − garbage). With p_uncond ≈ 0.1 the network learns a proper unconditional field at little cost to the conditional one.
2. Cost: less diversity (mode dropping, samples pushed to the "most typical" region), and with large w, oversaturated or out-of-distribution outputs. For robot actions: extreme velocities or poses never in the data, jerky motion, collisions; actions are bounded physical commands, so keep w modest and clip.
3. Typically the instruction (null = empty/padded instruction), to strengthen language following when the policy tends to ignore it. Guiding on the image (null = blank image) is less common; it can strengthen visual grounding. Both possible with separate weights (compositional guidance).
4. Batch the two passes together (one forward with batch 2N); share the conditioning encoder output (compute VLM features once, only the small action expert runs twice); apply guidance only at some steps; or distill the guided model into a single unguided student.
5. v = (1−2) v_c + 2 v_u = 2 v_u − v_c: it moves away from the instruction, an "anti-guidance": the robot does the opposite of what you asked more strongly.
6. Maybe, if the failure is "the policy is uncertain and averages toward a generic behavior". Test: counterfactual instruction set (same scenes, swapped targets), measure instruction-following rate at w = 1, 1.5, 2, 3 with a pre-registered bar (e.g. +15 points) and check success/collisions do not drop; 20+ scenes, paired, bootstrap CI. If following stays at 70% for all w, the problem is upstream (language not grounded in the representation): more language diversity in data or co-training.

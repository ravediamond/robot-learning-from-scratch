# Model answers

1. Train: `x1 (B,H,D); x0 = randn_like(x1); t = rand(B); xt = (1-t)x0 + t x1; loss = ((v(xt, t, obs) - (x1 - x0))**2).mean()`. Sample: `x = randn(B,H,D); for i in range(N): x = x + v(x, i/N, obs)/N`.
2. At t = 0 the input is pure noise, independent of which data point it will be paired with; so the L2-optimal velocity is E[x1] − x0, and one full step lands exactly on E[x1]: the mean. Information about the mode appears only as x_t moves toward data; multi-step integration lets the trajectory follow the conditional field into one mode.
3. Given (x_t, t), many (x0, x1) pairs pass through that point, with different x1 − x0. The network regresses the conditional expectation E[x1 − x0 | x_t]; the residual variance of the individual targets remains in the loss. That expected field is what transports noise to data (the flow matching theorem).
4. If the marginal velocity field were straight (constant along each path), one Euler step would be exact. Linear interpolation paths are straighter than diffusion's curved paths, so the learned field curves less and fewer steps suffice; rectification (reflow) straightens further.
5. The network learns the velocity at points (1−t) data + t noise labelled with t, i.e. a field indexed with the time reversed relative to the sampler. The sampler queries v at "t small" with noise-like x, where the network learned about data-like inputs: it extrapolates; samples drift off to wrong places.
6. Distillation: train a student to match the multi-step teacher's output in 1–2 steps (consistency models, shortcut models, progressive distillation), or reflow to straighten paths. Keep the noise input so different noises still map to different modes. Validate by comparing mode coverage and success rate against the 10-step teacher.

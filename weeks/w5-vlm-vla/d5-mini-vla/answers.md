# Model answers

1. Typical: right instruction ~0.95, swapped ~0.93: the target changes with the instruction while the scene is the same, so language is used. Blank image: success near 0 (or only by luck): vision is used. Pad colour: mostly goes to one colour or wanders. Two flow steps: some drop (near-mean behaviour) but the task is unimodal per instruction, so less than in the obstacle world.
2. An unseen token gives an embedding the model never conditioned on: behaviour is arbitrary (one default target, or between them). Real VLAs: paraphrases and new words are out of distribution unless pretraining/co-training covers them; test instruction robustness explicitly (paraphrase sets), don't assume the VLM's language skills transfer to control.
3. The prefix (21 tokens through 2 blocks) does not depend on x_t or t; recomputing it at each of 10 Euler steps would multiply its cost by 10. Here the prefix is about half the compute per step, so caching saves ~45%. In SmolVLA the VLM prefix is by far the largest part (hundreds of millions of params vs the small expert): caching it is what makes 10 flow steps affordable.
4. patchify + Linear ↔ SigLIP vision encoder + pixel-shuffle + projector; Embedding ↔ the LM's tokenizer and embeddings; 2 prefix blocks ↔ the VLM layers (first half); state token ↔ state projection; cross + causal self blocks ↔ interleaved CA/SA action expert; flow matching ↔ same. Scale: 64-dim vs 960-dim, 16 tokens vs 64 per camera, millions of pretraining pairs. Kind: their VLM is pretrained on internet image-text (semantics, robustness); ours is trained from scratch on one toy task: no generalisation beyond it.
5. A learned position table must discover the 2D geometry from data (each of 16 embeddings independently); coordinates as input give geometry for free and are linear in position, so attention can read target coordinates directly. Elsewhere: CoordConv, spatial-softmax keypoints (W2 D3), NeRF/positional encodings of xyz, 2D sin-cos ViT positions, RoPE in 2D.
6. (1) Counterfactual instructions on fixed scenes (swap target colour/object), paired, with Wilson CIs. (2) Paraphrases and unseen synonyms. (3) Distractors: same instruction with an extra similar object. (4) Blank/irrelevant instruction: does it still act, and how? (5) Vision ablations: camera blanked/shifted; plus the base rate: success when the instruction is ignored (≈ 1/number of candidates). Pre-register bars before running.

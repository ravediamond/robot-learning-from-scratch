# Model answers

1. Pixel shuffle: lossless rearrangement into channels, no parameters, fixed r², the LM sees a coarser grid. Average pooling: cheaper, loses information (averages features). Learned resampler (Perceiver/Q-Former): a fixed number of learned queries cross-attend to all patches: flexible count, can select relevant content, extra parameters and training, may drop details nobody asked for.
2. Prefix tokens never attend to state or action tokens, so their keys/values are a function of the images and text only; during the ~10 flow steps only the action tokens change, so the prefix K/V are computed once and reused. Breaks if the prefix attended to later blocks (full bidirectional mask) or if the actions were inserted before the text.
3. With a 4×4 grid and r = 2, the first merged token holds tokens 0,1,2,3: the whole top row, not a 2×2 block; neighbours across rows are split. Spatial neighbourhoods are destroyed, and the positional structure the ViT learned no longer matches what the LM sees. Worse than lower resolution because each token mixes far-apart columns.
4. State changes every control step while images/text could be shared, and the state is the most action-relevant signal; putting it in its own block lets it see the scene (to interpret itself in context) without the vision-language prefix depending on it, which keeps the prefix cacheable and the VLM features task-generic. In SmolVLA the state is projected to one token in the prefix sequence.
5. Sequence +64 tokens (with shuffle), mask: the new tokens join block 1. Latency: prefix cost grows (attention ~quadratic in prefix length, projection linear). Data: the camera must exist, be calibrated and synchronized in all training episodes; the model must learn when to use it; ablate to check it helps.
6. Three blocks: [images + language] bidirectional, [state] sees prefix, [actions] see everything before and each other. Actions are generated jointly by flow matching (all H tokens denoised together, not autoregressively), so bidirectional attention among them lets the chunk be coherent; there is no need for causality because no action is generated before another.
